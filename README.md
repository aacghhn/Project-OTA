# 프로젝트 목적

이 프로젝트는 숙소 예약 서비스를 구현하는 백엔드 개발자 포트폴리오다. 서비스 기능을 개발하며 발생하는 문제를 해결하고, 설계 판단의 근거와 검증 결과를 보여주는 것이 목적이다.

다음을 설명할 수 있는 결과물을 만든다.

- 어떤 상황을 왜 문제라고 판단했는가.
- 어떤 동작과 보장이 필요했는가.
- 선택한 설계와 기술은 그 문제를 어떻게 해결하는가.
- 어떤 대안을 검토했고 왜 다른 선택을 하지 않았는가.
- 실패를 어떻게 재현하고 해결 결과를 확인했는가.
- 무엇을 보장하지 못하며, 그때 서비스는 어떻게 동작하는가.
